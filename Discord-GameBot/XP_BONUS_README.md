# ロールXPボーナス

- `/xpbonus set role:@ロール percent:25`：そのロールの獲得XPを＋25％（通常の125％）にする。5〜1000％の範囲、5％刻み。
- `/xpbonus remove role:@ロール`：加算設定を削除。
- `/xpbonus list page:1`：ロール・加算率・獲得率の一覧を10件ずつ埋め込みで表示。誰でも閲覧可能。

登録・変更・削除には「サーバー管理」権限が必要です。設定はサーバーごとで、複数の対象ロールを所持している場合は加算率を合計します。例：＋5％と＋10％を持っていれば合計＋15％（通常の115％）です。合計は個別設定の1000％上限に丸めません。ロール自体の付与・削除はしません。

対象はチャット、VC、ソロ・対戦ゲーム、カジノ、ショップ購入のXPです。8192クリアのレベル報酬も一度XPへ換算した分に加算します。ジュエル・チケットの枚数、管理者によるXP・レベル直接編集は変更しません。レベリングの無効化やクールダウンなど既存の条件は維持します。

小数点以下はサーバー・ユーザーごとに繰り越します。例：3XPに＋5％なら、7回で通常21XP＋追加1XPになります。端数はまだ獲得していないXPなので、整数の獲得表示には含みません。

設定・ロール情報・端数は `levels.sqlite3` に保存し、再起動と既存のDBバックアップに対応します。ゲーム報酬の重複処理や失敗時は端数も同じトランザクションで保護します。ロール情報は発言・コマンド・VC付与・ゲーム報酬時に確認します。HTTPでメンバー情報を確認できない場合、その付与ではロール加算を行いません。

`/rank`（他のメンバーを指定した場合も含む）に、現在所持している加算対象ロールごとの率と、合計加算率を表示します。対象なしなら＋0％を表示。ロールが11個以上ある場合は実行者用のページ切替ボタンで一覧を確認できます。表示は実行時点のロール情報です。既に獲得したXPや処理済みのゲーム報酬は再計算しません。
