# AI人物当て `/aki`

1. サーバーのチャットで `/aki` を実行します。
2. 有名人や架空のキャラクターを1人思い浮かべます。名前を入力する必要はありません。
3. 「はい／いいえ／わからない／たぶんそう／たぶん違う」のボタンで質問に答えます。
4. AIが候補を出したら「当たり！／違う」で判定します。

最初の質問は「実在する人物ですか？」です。その後は回答をもとにGeminiが質問や候補を生成します。最低4問の回答後から推測し、最大20問・3回の推測で終了します。推測が外れた場合は、その候補を除外して続けます。正確さはAIの知識・回答内容に依存します。公式アキネーターのAPIやデータベースは使用していません。

パネルは全員に見えますが、操作できるのは開始した本人だけです。1人につき同じサーバーで1ゲームまで。「終了」で中断でき、5分間操作しない場合も終了します。新規開始は30秒間隔、Bot全体で同時100ゲームまでです。Bot再起動時に進行中のゲームは終了するため、再度 `/aki` を実行してください。

既存の `/ai chat` と同じ `GEMINI_API_KEY` とサーバーの `/ai model` 設定を使用します。モデルはゲーム開始時に固定します。追加ライブラリは不要です。AIのAPI利用量に加算されるため、設定したキー・モデルの利用上限や料金が適用されます。起動時にAIへの通信は行わず、最初の回答ボタンを押してから通信します。

ゲームの質問・選択した回答・否定した候補をGoogle Geminiへ送信します。DiscordのユーザーID、チャンネルID、通常のチャット履歴は送信しません。ゲーム履歴はメモリー内のみで、終了時に破棄します。`/ai chat` の履歴・固定キャラ設定・保存済み思考設定は変更しません。ゲーム専用の短い出力・low相当の思考設定を使います（未対応モデルでは標準設定）。

1回のAI応答は待機を含め最大35秒です。通信エラー・利用制限・形式不正の場合は「再試行／終了」を表示し、再試行で回答を重複記録しません。処理中の連打・古い質問ボタンも受け付けません。APIキーや生のAPIエラー・生成内容をログに出しません。

GeminiのJSON出力を検証し、質問上限・推測上限・同一質問の繰り返しをアプリ側で確認します。API仕様参考：https://ai.google.dev/api/generate-content
