# 💎ジュエル・カジノ

サーバー内のゲーム用通貨「💎ジュエル」を使います。現金との交換・購入機能はありません。レベリングXPやMinecraftの通貨とは独立しています。

初期所持金は0ジュエル。`/jewel daily` で1日1回500ジュエルを受け取れます。日本時間0時に受取日が切り替わります。

## コマンド

| コマンド例 | 内容 |
| --- | --- |
| `/casino help` | ゲームと配当の説明 |
| `/casino slot wager:100` | 100ジュエルでスロット |
| `/casino coinflip wager:100 side:表` | コイントスの表裏を予想 |
| `/casino blackjack wager:100` | ブラックジャックを開始 |
| `/casino blackjack` | 進行中のゲームを再表示 |
| `/casino dice wager:100 number:6` | サイコロの出目1〜6を予想 |
| `/jewel balance` | 自分の残高。memberで対象者を指定可能 |
| `/gift member:相手 amount:100` | 相手に100ジュエルを送る（手数料なし） |
| `/jewel daily` | デイリー報酬を受け取る |
| `/jewel history` | 自分の取引履歴を最大10件表示 |
| `/jewel leaderboard` | サーバーの残高ランキング上位10人 |
| `/jewel edit mode:加算 amount:500 member:対象者` | 管理者によるジュエル編集 |

ゲームの賭け金は10〜10,000ジュエルで、3秒に1回利用できます。残高が不足している場合は実行しません。残高確認、報酬受取、履歴、編集の結果は実行者にだけ表示します。ゲーム結果とランキングはチャンネルに表示します。

`/jewel edit` は「サーバー管理」権限が必要です。modeは「加算・減算・指定」から選択し、memberを省略すると自分が対象です。編集値は0〜10億。減算は残高0で止まります。編集は実行者IDとともに取引履歴へ記録します。

## 配当

倍率は**賭け金を含む払い戻し額**です。例えば100ジュエルを賭けて1.9倍なら、払い戻し190・差し引き利益90です。小数点以下は切り捨てます。

| ゲーム・結果 | 払い戻し |
| --- | --- |
| スロット 💎3つ | 50倍 |
| スロット ⭐3つ | 20倍 |
| スロット 🔔3つ | 15倍 |
| スロット 🍒3つ | 10倍 |
| スロット 🍇3つ | 8倍 |
| スロット 🍋3つ | 5倍 |
| スロット ちょうど2つ一致 | 1倍（賭け金が戻る） |
| スロット すべて異なる | 0 |
| コイントス 的中 | 1.9倍 |
| サイコロ 的中 | 5.5倍 |
| コイントス・サイコロ 外れ | 0 |

スロットの各リールは6種類から独立・均等に抽選します。コイントスは表裏を均等に、サイコロは1〜6を均等に抽選します。乱数にはPythonのsecretsを使用します。

## 保存と重複対策

ジュエルはサーバーごと・ユーザーごとに管理し、SQLiteに保存します。新規ウォレットの初期所持金は0です。更新前から持っているジュエルは減らさず維持します。同じDiscord操作IDを再処理しても、再抽選・再引き落とし・再払い戻しは行いません。ゲーム結果と残高の変更を同じトランザクションで記録します。同時実行でも残高をマイナスにしません。通信の問題でDiscordへの結果表示だけが失敗した場合は `/jewel history` で処理済みの結果を確認してください。

保存先は以下の優先順です。

1. `CASINO_DB_PATH` 環境変数で指定したファイル。
2. `LEVEL_DB_PATH` が設定されていれば、そのファイルと同じフォルダー内の `casino.sqlite3`。
3. 既定は `Discord-GameBot/casino.sqlite3`。

MWSではGitHubの最新版を取り込んで再起動してください。起動ファイルは `cloud_main.py` のままです。追加ライブラリやAPIキーは不要です。再デプロイで消えないよう、必要に応じてMWSで保持される保存先を指定してください。`CASINO_DB_PATH` はSQLiteファイルのパスであり、永続ストレージを新しく作る設定ではありません。保存先を変えるときはBotを停止して既存ファイルを移してください。

バックアップもBotを停止してから行ってください。残高・履歴ファイルをGitHubにはアップロードしません。同じBotを複数プロセスで起動しないでください。

## ジュエルを送る

`/gift member:送り先 amount:送る数` で同じサーバーの人間に送れます。送れる数は1〜10億、手数料はありません。自分自身・Botへの送金、残高不足、相手の保有上限超過は受け付けません。

送金元の引き落とし・相手への加算・双方の履歴をまとめて保存し、途中失敗時はすべて取り消します。同じ操作の再処理でも二重送金しません。成功メッセージはチャンネルに表示し、残高は公開しません。送金元は `/jewel history` に「送金」、送り先は「受取」として記録されます。

## 🃏 ブラックジャック

`/casino blackjack wager:100` で100ジュエルを賭け、「ヒット」「スタンド」のボタンで遊びます。賭け金は10〜10,000ジュエルです。最初に賭け金を預かり、終了時に払い戻します。

- 52枚の1デッキをゲームごとにシャッフルします。Aは1または11、絵札は10です。
- 最初は自分とディーラーに2枚ずつ配り、ディーラーの2枚目は終了まで隠します。
- ヒット：1枚追加。21を超えると負け、21になれば自動でスタンドします。
- スタンド：手札を確定。ディーラーは17未満で引き、ソフト17を含む17以上で止まります。
- 通常勝利は賭け金の2倍、最初の2枚で21なら2.5倍を払い戻します。両者が最初から21なら引き分けです。引き分けは賭け金を返却、負け・バストは払い戻し0です。倍率は賭け金込みで、小数点以下は切り捨てます。
- ダブルダウン、スプリット、保険、サレンダーはありません。

同じサーバーで1人1ゲームだけ進行できます。進行中にもう一度コマンドを入力すると、指定した賭け金にかかわらず既存のゲームを再表示し、新しい賭け金は取りません。操作できるのは開始した本人だけです。連打や古いボタンの操作でカードを二重に引いたり、二重精算したりしません。

2分間ヒット・スタンド操作がない場合は自動スタンドします。Botが停止している間も期限は維持し、次回起動時に期限切れのゲームを精算します。再起動後はボタンを復元し、`/casino blackjack` でも進行中ゲームを再表示できます。再表示で期限は延長しません。

残高・手札・山札・期限・操作履歴は既存の `casino.sqlite3`（CASINO_DB_PATH）に保存します。引き落としと払い戻しは `/jewel history` に別々の履歴として残ります。通信の問題で表示に失敗した場合も、再表示すれば保存した進行状況を確認できます。

MWSで最新版を取り込んでBotを再起動してください。PCブリッジの更新は不要です。既存の残高は維持します。
