# 💎ジュエル・カジノ

サーバー内のゲーム用通貨「💎ジュエル」を使います。現金との交換・購入機能はありません。レベリングXPやMinecraftの通貨とは独立しています。

初期所持金は1,000ジュエル。`/jewel daily` で1日1回500ジュエルを受け取れます。日本時間0時に受取日が切り替わります。

## コマンド

| コマンド例 | 内容 |
| --- | --- |
| `/casino help` | ゲームと配当の説明 |
| `/casino slot wager:100` | 100ジュエルでスロット |
| `/casino coinflip wager:100 side:表` | コイントスの表裏を予想 |
| `/casino dice wager:100 number:6` | サイコロの出目1〜6を予想 |
| `/jewel balance` | 自分の残高。memberで対象者を指定可能 |
| `/jewel daily` | デイリー報酬を受け取る |
| `/jewel history` | 自分の取引履歴を最大10件表示 |
| `/jewel leaderboard` | サーバーの残高ランキング上位10人 |
| `/jewel edit mode:加算 amount:500 member:対象者` | 管理者によるジュエル編集 |

ゲームの賭け金は10〜10,000ジュエルで、3秒に1回利用できます。残高が不足している場合は実行しません。残高確認、報酬受取、履歴、編集の結果は実行者にだけ表示します。ゲーム結果とランキングはチャンネルに表示します。

`/jewel edit` は「サーバー管理」権限が必要です。modeは「加算・減算・指定」から選択し、memberを省略すると自分が対象です。編集値は0〜10億。減算は残高0で止まります。編集は実行者IDとともに取引履歴へ記録します。

## 配当

倍率は**賭け金を含む払い戻し額**です。例えば100ジュエルを賭けて1.9倍なら、払い戻し190・差し引き利益90です。小数点以下は切り捨てます。

| ゲーム・結果 | 払い戻し |
| --- | --- |
| スロット 💎3つ | 50倍 |
| スロット ⭐3つ | 20倍 |
| スロット 🔔3つ | 15倍 |
| スロット 🍒3つ | 10倍 |
| スロット 🍇3つ | 8倍 |
| スロット 🍋3つ | 5倍 |
| スロット ちょうど2つ一致 | 1倍（賭け金が戻る） |
| スロット すべて異なる | 0 |
| コイントス 的中 | 1.9倍 |
| サイコロ 的中 | 5.5倍 |
| コイントス・サイコロ 外れ | 0 |

スロットの各リールは6種類から独立・均等に抽選します。コイントスは表裏を均等に、サイコロは1〜6を均等に抽選します。乱数にはPythonのsecretsを使用します。

## 保存と重複対策

ジュエルはサーバーごと・ユーザーごとに管理し、SQLiteに保存します。初期所持金はウォレット作成時の1回だけです。同じDiscord操作IDを再処理しても、再抽選・再引き落とし・再払い戻しは行いません。ゲーム結果と残高の変更を同じトランザクションで記録します。同時実行でも残高をマイナスにしません。通信の問題でDiscordへの結果表示だけが失敗した場合は `/jewel history` で処理済みの結果を確認してください。

保存先は以下の優先順です。

1. `CASINO_DB_PATH` 環境変数で指定したファイル。
2. `LEVEL_DB_PATH` が設定されていれば、そのファイルと同じフォルダー内の `casino.sqlite3`。
3. 既定は `Discord-GameBot/casino.sqlite3`。

MWSではGitHubの最新版を取り込んで再起動してください。起動ファイルは `cloud_main.py` のままです。追加ライブラリやAPIキーは不要です。再デプロイで消えないよう、必要に応じてMWSで保持される保存先を指定してください。`CASINO_DB_PATH` はSQLiteファイルのパスであり、永続ストレージを新しく作る設定ではありません。保存先を変えるときはBotを停止して既存ファイルを移してください。

バックアップもBotを停止してから行ってください。残高・履歴ファイルをGitHubにはアップロードしません。同じBotを複数プロセスで起動しないでください。
