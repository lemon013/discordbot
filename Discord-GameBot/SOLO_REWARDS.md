# 1人用ゲームの報酬

| ゲーム | 付与タイミング | 報酬 |
| --- | --- | --- |
| `/kakigoori` | 1杯以上盛り付けて「完成！」 | 3XP。作り直して完成させると次の1回分 |
| `/aki` | 正解・3回不正解・AIのギブアップでゲーム終了 | 3XP。自分で中断・時間切れ・通信失敗だけでは付与しない |
| `/casino slot`・`coinflip`・`dice` | 賭けが成立して結果確定 | 3XP、収支がプラスの勝利は合計5XP |
| `/casino blackjack` | 決着時（自動スタンドを含む） | 敗北・引き分け3XP、勝利・ブラックジャック5XP |
| `/8192game` | 2回連続成功で1/4に到達してから | 下の表に従って成功のたびに付与 |

残高表示・ヘルプ・デイリー・不正な賭け・残高不足・進行中ゲームの再表示ではゲームXPは付与しません。

| 連続成功回数 | 達成確率 | 今回もらえるXP |

| 2 | 1/4 | 3 |

| 13 | 1/8192・クリア | 36＋クリア報酬 |

`/8192game` のクリア報酬は **さらに3レベル＋3000ジュエル**。成功報酬の累計は234XPです。最後の36XPを先に加え、その時点から3レベル上げます。レベル内の進捗XPは維持し、既存の最大レベル100を超えません。通常のレベルアップによるジュエル・ロール報酬も従来どおり別途処理します。

途中で失敗・時間切れになっても、それまでに獲得したXPは失いません。10分間操作しない `/8192game` は終了し、再度開始できます。Bot再起動で進行中のかき氷・アキネーター・8192ゲームは終了しますが、付与済み報酬は保持します。ブラックジャックは従来どおり再開できます。

報酬はゲーム・ラウンド・成功回数ごとのIDで記録します。同じボタンの連打・過去のボタン・結果の再表示で二重付与しません。XP・レベル・ジュエルの変更は既存のSQLiteデータベースを使ってまとめて確定します。カジノでは掛け金・払い戻し・XPも同じ取引で保存します。報酬保存に失敗したかき氷・アキネーター・8192ゲームは、表示された操作で再試行できます。通知だけ失敗した場合も、保存済みの報酬は保持します。
