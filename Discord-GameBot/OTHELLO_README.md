# オセロ

`/othello` で2人対戦を募集します。募集主は自動参加し、もう1人が「参加／退出」を押したら、募集主が「開始」を押します。先手の黒・後手の白はランダムです。同じチャンネルでは同時に1対局までです。

## 2連続置き

任意項目「連続置き回数」は各プレイヤーが1試合に使える回数です。0〜10回を設定でき、初期値は1回です。0回なら通常ルールになります。

例：`/othello 連続置き回数:3` で、双方が3回ずつ特技を使えます。

任意項目「連続置き解禁ターン」は1〜60で設定でき、デフォルトは5ターン目です。黒・白を合わせた実際の着手数で数えます。通常の5ターン目は黒の3手目です。連続置きの2手目も1手と数え、自動パスでは手数を増やしません。

例：`/othello 連続置き回数:3 連続置き解禁ターン:10` で、10ターン目から双方が3回ずつ使用できます。解禁を1にすると、初手の連続置きで白が全滅し、即決着する場合があります。

- 通常は「コマを置く」を押し、A1〜H8の位置を入力します。
- 特技を使う手番では「2連続で置く」を押して1手目の位置を入力します。
- 1手目が合法なら1回分を消費し、続けて同じプレイヤーがもう1枚置けます。2手目は「コマを置く」から入力します。
- 置けない場所への入力・フォームを閉じる操作では回数を消費しません。
- 連続置きの2手目では、さらに特技を使うことはできません。
- 2手目に合法手がない場合は自動パスします。この場合も使用回数は消費します。

## 盤面と勝敗

8×8の盤面で、⚫が黒、⚪が白、🟩が空き、🟨が現在置ける場所です。盤面には列A〜Hと行1〜8を表示し、合法手も座標で併記します。縦・横・斜めに相手のコマをはさんで反転させます。

相手に合法手がなければ自動パス。双方が置けなくなったら、盤面に空きがあっても終了し、枚数が多い方の勝利です。同数なら引き分けです。

募集は5分、各手番は3分で時間切れになります。投了は参加者が「投了する」→確認ボタンで確定します。Bot再起動で対局は中断し、続行できなくなります。

## 報酬

- 完走した勝者：100ジュエル＋10XP。
- 完走した敗者・引き分けの双方：50ジュエル＋5XP。
- 募集中止・投了・時間切れ：双方とも報酬なし。

既存のジュエル・レベル口座に加算します。処理に失敗した場合は募集主が「報酬を再試行」を押せます。同じ対局の受取済み報酬は二重加算しません。

通常の起動方法でBotを再起動すると、既存のコマンド同期処理で `/othello` を登録します。
