# スペシャルチケット

サーバーごとに所持数を保存します。所持数確認は `/ticket balance`、全所持者のランキングは `/ticket leaderboard` です。Discordの仕様上、子コマンドを持つ `/ticket` 自体は直接実行できません。ランキングは10人ずつページ送りでき、名前・ID・所持数・全チケットに対する保有割合を表示します。0枚の人はランキング対象外です。割合は表示時のスナップショットで、小数点以下4桁まで表示します。

| 正常終了した機能 | 配布 |
| --- | --- |
| `/8192game`・`/8192games` | 挑戦の失敗・クリアで実行者に1枚。途中成功では配布しません |
| `/aki` | 回答後の正常なゲーム結果確定時に実行者に1枚 |
| `/casino` の各ゲーム（ブラックジャックを含む） | 決着ごとに実行者に1枚 |
| `/kakigoori` | シロップを盛って「完成！」で確定したときに1枚 |
| `/tensei` | 最初の人生の出力完了で1枚。同じパネルの再抽選は追加配布なし |
| `/sound play` | 添付音声・動画の音声が最後まで正常再生されたときに実行者に1枚 |
| メッセージアプリ「高専適正度」 | 返信成功時にアプリを実行した人へ1枚 |
| `/guess number`・`/insider`・`/ito`・`/wordwolfex`・`/othello` | 既存の終了報酬と同時に参加者それぞれ3枚。勝敗で枚数は変わりません |
| `/play`・検索結果の候補ボタン | 正常に再生完了した曲の追加者へ3枚。プレイリストは完了した各曲が対象 |

開始前の取消、単なるコマンドエラー、音声の取得失敗・途中停止・スキップには配布しません。未操作で終了した1人用ゲームも対象外です。音声の到達・聴取までは保証できないため、再生処理の正常完了で判定します。ループは同じキュー項目への配布1回までです。サウンドボード・読み上げ・テスト音は対象外です。更新前の結果への遡及配布はありません。

`/shop` →「🎟️ スペシャルチケット」から500ジュエルで1枚購入できます。複数回購入可能です。ジュエルの支払いとチケット加算は同じSQLiteトランザクションで確定します。XP・既存のジュエル報酬は継続します。特典を装備する扱いにはせず、Minecraft同期の対象にも含めません。

`/tyuusen` はユーザーID `799820074990698496` だけが実行できます。そのサーバーの抽選時点の所持数で、1枚1口として暗号学的乱数で1人選び、名前・ID・口数・確率を埋め込みに表示します。チケットは抽選で消費しません。繰り返しの抽選では同じ人が当たることもあります。抽選結果はDBに記録し、同じ操作の再送では抽選し直しません。

チケット・配布履歴・抽選履歴は既存の `casino.sqlite3` に保存します。通常のBot再起動で保持され、既存のDiscordバックアップの対象にも含まれます。バックアップからDB全体を復元する検証も行っています。MWSがローカル保存領域ごと破棄した場合は最新バックアップ時点への復元になるため、直近の未同期分までの保持は保証できません。既存のバックアップは60秒ごとです。
