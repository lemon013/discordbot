# 個人設定パネル

サーバー内で `/settings` を実行すると、実行者だけに見える設定パネルを表示します。VC未参加でも操作できます。

- 読み上げ音声：接続先で取得できたVOICEVOX音声を25件ずつ表示して選択。
- 読み上げ速度：フォームで0.5〜2.0倍を指定。
- 自分の発言の読み上げ：OFFなら読み上げ対象外。既に音声生成・再生を開始した発言には遡及しません。待機中の発言は音声生成前にも確認します。
- レベルアップ通知：自分の通常のレベルアップ通知と、レベル報酬ロール付与時のお祝いをON/OFF。XP・ジュエル・ロール付与は継続します。ONでもサーバー全体の通常レベルアップ通知が無効なら有効にはなりません。

設定はサーバー共通の個人設定です。読み上げ音声・速度は既存 `/voice change` と同じ保存先を使います。音量や読み上げ対象のサーバー共通ルールは既存の管理者用 `/voice` コマンドで変更します。

パネル・音声選択・入力フォームは作成者だけが操作でき、パネルは3分で期限切れになります。再度 `/settings` を実行してください。音声クレジットはBotのプロフィール欄と `/voice credits` を参照してください。

`levels.sqlite3` 内の既存 `voice_preferences` テーブルに保存します。音声はuserスコープ、ON/OFF設定はpersonalスコープで、他の設定を維持して変更分を保存します。再起動後も保持され、既存のデータベースバックアップにも含まれます。新しい常駐ポーリング処理や音声生成は追加しません。
