# シフォン専用 Gemini AIチャット

## 最初の設定

1. https://aistudio.google.com/apikey でGemini APIキーを取得します。
2. MWSでは環境変数に、PCではこのフォルダーの `.env` に `GEMINI_API_KEY=取得したキー` を設定します。DiscordのBotトークンとは別のキーです。チャットには貼らないでください。
3. Botを通常の起動方法で再起動します。`START_ALL.bat` / `main.py` / `cloud_main.py` からの起動に対応します。
4. Discord Developer Portalで、このBotの **Message Content Intent** を有効にしてください。
5. Botには送信先の「チャンネルを見る」「メッセージを送信」権限、スレッドでは「スレッドでメッセージを送信」権限が必要です。

起動時にDiscordへ `/ai` コマンドを同期します。表示されない場合はBotの再起動後にDiscordを再読み込みし、Botのコマンド同期ログと `applications.commands` の導入権限を確認してください。

追加ライブラリはrequirements.txtに記載済みです。手動起動する場合は先に `python -m pip install -r requirements.txt` を実行します。

## コマンド

Discordのスラッシュコマンドです。`/ai` を入力してサブコマンドを選択してください。DMには応答しません。`/ai help` で使い方を確認できます。

| 入力 | 動作 |
| --- | --- |
| `/ai` | ヘルプ |
| `/ai chat こんにちは` | シフォンと会話 |
| `@Bot 質問` | 実際にBotをメンションして質問 |
| `/ai settings` | モデル・思考設定・キャラ設定が固定であることを表示 |
| `/ai models` | APIキーで利用可能なモデルを取得。無料モデル限定の一覧ではありません |
| `/ai model gemini-2.5-flash` | モデルを変更（サーバー管理者） |
| `/ai prompt 任意の文字列` | 互換性用。設定変更は受け付けません（resetも同様） |
| `/ai reasoning low` | 思考レベルを変更（サーバー管理者） |
| `/ai reset` | 現在のチャンネルの全ユーザーのAI会話履歴を削除（サーバー管理者） |

質問への回答はチャンネルに公開し、設定・ヘルプ・モデル一覧・リセットの結果は実行者だけに表示します。

設定はサーバーごとに `ai_settings.json` に保存し、再起動後も維持します。モデル・思考設定の変更時は、そのサーバーの履歴を削除します。モデル変更時は思考設定もautoに戻します。キャラ設定はコード内の SYSTEM_INSTRUCTION に固定し、過去に保存された prompt は使用しません。settingsにも内部指示文は表示しません。

既定モデルは `gemini-2.5-flash`、思考設定は `auto` です。既定モデルは `.env` の `GEMINI_MODEL` でも変更できます。利用できない場合は `/ai models` で現在のモデルIDを調べて変更してください。

## 思考設定

- `auto`：モデルの標準設定。最初はこれを使用してください。
- Gemini 2.5系：`off=0`、`minimal=512`、`low=1024`、`medium=4096`、`high=8192` の思考トークン予算に変換します。2.5 Proのoffは使えません。
- Gemini 3・4系：`minimal / low / medium / high` をAPIに送ります。選べる値はモデルにより異なり、非対応の組み合わせはAPIに拒否されます。エラー時はautoに戻してください。offは対応しません。
- その他のモデル：autoのみ。思考内容そのものはDiscordに表示しません。

## 会話と利用上限

会話履歴はサーバー・チャンネル・ユーザーごとに分離します。他のユーザーのAI会話は引き継ぎません。通常の雑談は取り込みません。AIを呼んだ質問と、最大6往復のAI会話のみGoogleに送ります。添付ファイルの読み取り・Web検索・サーバーの操作はしません。

履歴はメモリ内のみで、最終回答から1時間で次回利用時に失効し、Bot再起動でも消えます。保持は最大128会話です。同一チャンネルの同時質問は待機を案内します。ユーザーごとに5秒の間隔、Bot全体で最大3件の同時質問に制限します。

無料枠はGoogle側のモデル・プロジェクトの条件に従います。上限超過時は案内を表示し、自動でモデル切り替えや課金設定の変更はしません。課金が有効なプロジェクトのキーでは利用料金が発生する場合があります。無料利用を希望する場合は、Google AI Studioでプロジェクトの課金状態と料金表を確認してください。無料枠では送信内容が製品改善に使用される場合があります。

APIキーがない状態でも既存のゲーム機能は使えます。キー設定後は再起動が必要です。

公式資料：
- https://ai.google.dev/gemini-api/docs/pricing
- https://ai.google.dev/gemini-api/docs/generate-content/thinking
- https://ai.google.dev/api/generate-content

## 固定キャラクターと設定保護

シフォンは「ぐりーんの鯖！」のマスコットで、生みの親はちょこもち（あだ名：高専）。明るくポジティブで簡潔に話し、語尾に「リミ」を付けます。名前・所属・生みの親は公開情報として紹介できます。

絵文字は返信全体で最大2個に固定し、「絵文字を沢山つかって」「今回だけ増やして」などの指定では変更しません。代表的な装飾・話し方の変更要求は定型文で案内します。単に絵文字について質問することはできます。モデルが上限を超えて返した場合も、送信前に超過分を取り除きます。家族・肌色・国旗・キーキャップ・Discordカスタム絵文字は各1個として扱います。上限超過した元の回答を次の会話に持ち越さないため、そのユーザーの該当会話履歴を削除します。

毎回のGeminiリクエストに同じ systemInstruction を渡し、利用者の質問は user ロールの contents に分離します。会話、旧 ai_settings.json の prompt、/ai prompt から固定設定を上書きできません。既存のモデル・思考設定と管理者権限チェックは維持します。

代表的な設定変更・内部指示開示の依頼はAPI呼び出し前に定型文で断り、履歴にも保存しません。回答に内部規則の原文が含まれる場合は定型文に差し替え、そのユーザーの該当会話履歴を削除します。語尾の抜けは送信時に補完し、Geminiの思考署名を含むAPI履歴は改変しません。

これらは設定の上書きを防ぎ、誘導への耐性を高める設計です。生成AIの発言の逸脱や、未知の誘導による指示文の言い換え・符号化などを完全に防ぐ保証はありません。APIキー・Botトークン・環境変数の値はプロンプトや履歴に注入せず、ツール実行権限も与えません。

自動テストではAPI通信をモック化し、固定指示・旧設定互換・権限・履歴分離・開示要求拒否・署名保持・エラー時の秘密保護を確認します。Gemini実APIの応答品質とDiscord上の最終動作は、運用環境で確認してください。
