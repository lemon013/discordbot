# ito・インサイダー（Discord Bot版）

## 共通

- `/ito` または `/insider` で募集。募集主は自動参加。
- 「参加／退出」で参加し、募集主が「開始」を押します。
- 2つのゲームを合わせ、同じサーバーで同時に1試合まで。
- 秘密情報はボタンを押した本人だけに表示。DMの許可は不要。
- 勝利は100ジュエル＋10XP、敗北は50ジュエル＋5XP。既存の口座に加算します。
- 中止・募集の期限切れ・準備未完了での時間切れは報酬なし。
- 報酬処理に失敗したら募集主が結果の「報酬を再試行」を押します。受取済みの報酬は重複しません。
- `/jewel balance` で残高を確認できます。
- 進行状態と秘密情報はメモリ上に保持するため、Bot再起動で試合は中断します。

## /ito（2〜10人）

1. 各自「自分の数字」で1〜100の秘密の数字を確認。
2. お題に合う例えを「ヒント入力」から提出。全員のヒントは公開されます。
3. 数字を直接伝えるのは禁止。1に近いほど弱い・低い、100に近いほど強い・高いものを例えにします。
4. 全員のヒントがそろったら、会話で順序を相談。
5. 小さいと思う人から「自分のカードを出す」を押します。
6. 小さい数字が残っているのに大きい数字を出すと全員敗北。最後まで昇順なら全員勝利。

募集10分、ゲーム開始後10分で時間切れ中止。カードをまだ出していない人はヒントを修正できます。
数字は初期設定では全員異なります。`/ito` の任意項目「数字の重複」をTrueにすると、同じ数字が配られる場合があります。
募集主は募集ボードの「数字の重複：あり／なし」ボタンでも切り替えられます。開始後は変更できません。
重複ありの場合、同じ数字の人はどちらが先にカードを出しても正解です。範囲はどちらも1〜100です。
お題はBot独自のお題です。

## /insider（4〜8人）

1. 募集主が公開のマスター。ほかの参加者からインサイダー1人をランダムに決定。
2. 全員が「役職・お題を確認」を押します。お題が見えるのはマスターとインサイダーだけ。
3. 全員確認後、マスターが「クイズ開始」を押します。
4. チャットまたはVCでマスターに質問。マスターは「はい／いいえ」などで回答します。
5. 5分以内に正解したらマスターが「正解！」を押し、正解を公開。
6. 3分間、誰が答えを知って誘導していたか議論。マスターは早めに投票へ進めることもできます。
7. 全員が秘密投票。全票がそろうか1分が経過すると結果を発表します。

Bot版は一斉投票1回に簡略化しています。マスターは投票できますが、公開役職なので投票対象にはなりません。
最多票が単独でインサイダーならマスター・庶民が勝利。それ以外（同票・全員未投票を含む）はインサイダー勝利。
クイズが5分で解けなかった場合は全員敗北。未投票は棄権として扱います。
募集10分、役職確認3分で時間切れ中止。Botは自由文の質問への自動回答や正解の自動判定を行いません。
