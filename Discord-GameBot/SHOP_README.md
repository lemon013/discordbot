# 🛒 ジュエルショップ

`/shop` を入力すると、自分専用の埋め込みボードと商品選択メニューが出ます。1つ選んで詳細を確認し、「購入する」で確定します。購入済みの音・歓迎文は「装備する（無料）」で切り替えられます。操作できるのは開いた本人だけです。

| 商品 | 価格 |
| --- | --- |
| 5XPアップ（何度でも購入可能） | 1,000ジュエル |
| レコード：カメラ `random.screenshot` | 2,000ジュエル |
| レコード：経験値 `random.orb` | 2,500ジュエル |
| レコード：レベルアップ `random.levelup` | 3,000ジュエル |
| ようこそ：野生のプレイヤー | 3,000ジュエル |
| ようこそ：主役登場 | 3,500ジュエル |
| ようこそ：盛大な歓迎 | 4,000ジュエル |

商品は `shop_catalog.json` に定義しています。追加・変更時はMWS側とPC側を同じ内容に更新してください。

## 購入の動作

- 5XP：累計XPとショップ購入XPが5増えます。Lv.100の上限は維持します。Lv.30に達すれば常連ロールの対象です。ジュエルの引き落としとXP付与を同じSQLiteトランザクションで処理します。
- レコード：装備中の持ち主がMinecraftへ参加したとき、そのワールド内の参加者全員に効果音を再生します。音楽ディスクではなく参加時の効果音です。
- ようこそメッセージ：装備中の持ち主が参加したとき、そのワールドへ歓迎文を送信します。例は `あ！野生の<プレイヤーネーム>だ！`。実際のMinecraft名に置き換えます。
- 音と歓迎文は各1つ装備できます。初回購入で自動装備します。買い切り商品は再購入でジュエルを消費しません。
- 同じ購入操作を再処理しても二重引き落とし・XP重複付与をしません。残高不足なら変更しません。
- 同じ人の同じワールドへの10秒以内の重複参加イベントは、演出の重複再生を抑制します。

## MWS側の更新

GitHubの最新mainを取り込み、Botを再起動します。起動ファイルは `cloud_main.py` のままです。

ショップの購入情報と装備はジュエルDB（`CASINO_DB_PATH`）、購入したXPはレベルDB（`LEVEL_DB_PATH`）に保存します。これらが別ファイルの場合、XP購入は通常のSQLiteロールバックジャーナル方式を使用します。標準設定で動きます。外部からWALへ変更している場合は購入を停止して案内します。

Minecraft演出の同期にはMWS側に次の既存の成績同期設定が必要です。

| 環境変数 | 内容 |
| --- | --- |
| `MC_SYNC_CHANNEL_ID` | PCとの同期専用DiscordチャンネルID |
| `MC_SYNC_SECRET` | PC側と同じ32文字以上の共有キー |

同期専用チャンネルはPC BotとクラウドBotが閲覧・投稿できる非公開チャンネルを使用してください。クラウドBotには「メッセージを送信」「ファイルを添付」が必要です。購入・装備変更時に署名付きの装備情報を送信します。失敗時は60秒ごとに再試行し、変更がない場合も10分ごとに再送します。購入済み内容は同期失敗でも保持します。

## PC側の更新（参加演出に必要）

MWSの更新に加え、PC側にも最新版のファイルを反映して `START_PC_BRIDGE.bat` から再起動してください。今回の関連ファイルは以下です。

- `PC-Bridge/scripts/main.js`
- `Minecraft-Discord-Bridge/scripts/shopEffects.js`
- `Minecraft-Discord-Bridge/scripts/main.js`（従来の一体型ブリッジで起動する場合）
- `Discord-GameBot/shop_catalog.json`

`PC-Bridge/.env` の `MC_SYNC_CHANNEL_ID` と `MC_SYNC_SECRET` をMWS側と一致させます。成績同期が動いている場合は同じ設定をそのまま使えます。必要なら `MC_SHOP_SENDER_ID` にクラウドBotのユーザーIDを指定し、受信元も限定できます。未指定でも共有キーによる署名確認は必須です。

PC Botには同期チャンネルの「チャンネルを見る」「メッセージ履歴を読む」が必要です。PC側はBot起動時・60秒ごとの確認・新着メッセージで装備情報を読みます。ログの `[Shop] Join effects synchronized` を確認してからMinecraftへ参加し直してください。

購入者本人のMinecraftアカウントを、マイクラの `!link` → **PC Botの** `/link` で連携してください。既存の `account.json` にあるMinecraft名とDiscordユーザーIDで、演出の持ち主を判定します。他の人の参加には発動しません。

PCブリッジとワールドが接続中のときに動きます。Minecraft側でコマンド実行が許可されている必要があります。接続が切れている間の参加演出を後から再生することはありません。MWSだけ更新した場合、XP購入は使えますがMinecraftの参加演出にはPC側の更新が必要です。

## データの安全性

同期に送るのはDiscord IDと装備中の商品IDです。アカウント連携ファイル自体や共有キーは送信しません。PC側は署名、サーバーID、時刻、商品IDを確認し、同期データ内の任意コマンドや任意の音名・歓迎文は実行しません。歓迎文はコマンドではなくメッセージとして送ります。

データを失わないよう、Bot停止中にジュエルDBとレベルDBをまとめてバックアップしてください。
