# レベリング（テキスト・VC）

Bot起動後に自動で有効になります。Gemini APIや追加ライブラリ、音声接続は不要です。Minecraftのステータスとは別の、Discordサーバーごとのレベルです。

## 初期設定

| 項目 | 初期値 |
| --- | --- |
| テキスト発言 | 5〜15 XPを毎回ランダム、ユーザーごとに60秒に1回 |
| 通常VCへの参加 | 1分につき10 XP |
| 最初のレベルアップ | 300 XP（Lv.0 → Lv.1） |
| 次レベルの必要XP | 300 + 現在レベル × 50 |
| レベルアップ通知 | 有効。テキストは発言先。VCは通知先を設定した場合のみ |

Lv.2は累計650 XP、Lv.3は累計1050 XPです。最大レベルは100です。Lv.100到達後も累計XP・獲得内訳は記録し、ランキングに使います。`/rank` の次レベル欄はMAXと表示します。

## コマンド

| コマンド | 内容 |
| --- | --- |
| `/rank` | 自分のレベル・累計XP・次のレベルまでのXP・順位 |
| `/rank member:メンバー` | 指定メンバーのレベル |
| `/leaderboard` | サーバーのXPランキング（10人ずつ） |
| `/leaderboard page:2` | ランキングの2ページ目 |
| `/level settings` | 現在の設定（サーバー管理者） |
| `/level configure` | 獲得量・付与間隔・必要XP・有効無効・通知設定（サーバー管理者） |
| `/level notify channel:通知先` | テキスト・VC共通のレベルアップ通知先（サーバー管理者） |
| `/level notify` | 通知先を既定に戻す（サーバー管理者） |

例：`/level configure text_xp_min:5 text_xp_max:15 voice_xp:15 cooldown:60`。指定しなかった項目は維持します。`text_xp_min:0 text_xp_max:0` はテキストのみ無効、`voice_xp:0` はVCのみ無効、`enabled:False` は全体を停止します。`notifications:False` はレベルアップ通知のみ停止します。

`text_xp_min` と `text_xp_max` でテキストXPのランダム範囲を設定できます（両端を含む整数）。最小値は最大値以下にしてください。同じ値にすると固定XPになります。\n\n`base_xp` と `step_xp` は必要XPの設定です。変更すると、累計XPを維持したままレベルを再計算します。設定変更時はそのサーバーのVC計測を再開し、1分未満の端数はリセットします。

## 付与条件

- テキスト：空白のみの投稿、Bot、Webhook、DM、編集したメッセージは対象外です。添付ファイルのみの通常投稿は対象です。連投してもクールダウン中は加算しません。スラッシュコマンドの実行だけではテキストXPは増えません。
- VC：通常の通話チャンネル内に、対象の人間が2人以上いる間に計測します。AFKチャンネル、Bot、1人の部屋、サーバー側または本人のスピーカーミュート、ステージは対象外です。マイクミュート中も対象です。発話検出は行いません。
- 途中退室・ミュート変更でも、それまでの対象時間を精算します。1分未満の端数は対象外になったときに破棄します。対象VC間を移動し、引き続き条件を満たす場合は計測を継続します。
- Bot稼働中の時間のみ付与します。再起動・再接続では端数をリセットします。長い処理停止による空白時間には付与しません。
- XPは15秒ごとの確認、またはVC状態変更時に加算します。レベルアップ通知はメンション表記になりますが、通知のpingは送りません。

## MWSへの反映・保存

GitHubの最新mainを取り込み、Botを再起動します。起動ファイルは従来どおり `cloud_main.py` です。既存設定のMessage Content Intentと、通常のGuild Messages / Voice States Intentを使用します。Server Members Intent、音声ライブラリ、音声の録音は不要です。

XPとレベリング設定は既定で `Discord-GameBot/levels.sqlite3` に保存し、通常のBot再起動では維持します。`LEVEL_DB_PATH` 環境変数で、MWSの書き込み可能な永続保存領域のパスを指定できます。再デプロイで作業フォルダーが置き換わる環境では必ず永続保存先を指定するか、このファイルをバックアップしてください。バックアップ・復元はBotを停止してから行ってください。

Botを複数同時に起動すると、VC計測の重複やコマンドの競合が起こります。同じBotは1つのプロセスだけで動かしてください。保存ファイルはGitHubには含めません。

従来版からの更新時も保存済みXPは維持します。既存サーバーのテキスト獲得量は5〜15XPへ切り替わります。従来テキストXPを0で無効化していたサーバーは無効のまま維持します。

## Lv.30の常連ロール

Lv.30以上でXPを獲得すると、ロールID `1370764628354666688` を自動付与します。テキスト・VCの両方が対象です。すでにLv.30以上の人も次のXP獲得時に対象になります。該当ロールが存在するサーバーだけで動作します。

付与に成功した場合、次の文で祝います：

> 🎉常連ロールをゲットしました！おめでとうございます！

送信時は対象者のメンション表記を添えます（pingなし）。通知先を設定していればそのチャンネル、未設定ならテキストの発言先に送信します。VCの場合は参加中VCのテキスト欄、なければサーバーのシステムチャンネルを使用します。送信できる場所がない場合もロール自体は付与します。通常のレベルアップ通知を無効にしていても、この報酬とお祝いは有効です。

Botには「ロールの管理」権限が必要です。サーバーのロール設定でBotの最上位ロールを常連ロールより上へ配置してください。すでに持っている場合は再付与・再通知しません。失敗時は付与成功のお祝いを送らず、次のXP獲得時に再試行します。到達後にレベル設定を変更してLv.30未満になっても、この機能で付与済みロールを削除することはありません。
